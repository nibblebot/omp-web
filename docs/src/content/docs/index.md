omp-web is a web UI for running multiple oh-my-pi sessions across all your repos and worktrees.

Try the [live demo](https://nibblebot.github.io/omp-web/demo/): the real omp-web UI with fixture data, running in your browser with nothing to install.

## Getting started

- [Installation](/installation/): requirements, the one-line installer, verifying, self-update and manual install.
- [Running omp-web](/running/): commands, binding, the browser origin, resuming sessions and the session process.
- [Install as an app](/install-as-an-app/): the web UI as an installable app on Android.

## Operations
